# WS2812 灯带控制方案

> 状态：**已实现**（v1.1 修复 SPI 中断上下文超时）
> 版本：v1.1（2026-09-02）
> 原则：**不改变项目原有功能**（USB/BLE/三模/编码器/电池/低功耗），新增独立 LED 模块。

---

## 1. 需求对齐

| 编号 | 需求 | 本方案 |
|------|------|--------|
| L1 | 按键时对应灯位有渐隐效果 | `button_event` → 映射到 LED 索引 → 触发 fade 效果 |
| L2 | 上位机/设置页改主题后灯效颜色变化 | 新增 `theme_rgb_update_event`，LED 模块订阅并更新主题色 |
| L3 | 灯带关闭后不再发光 | 新增 `led_strip_en_event`，关闭时清屏并断电 |
| L4 | 生命周期和电源事件 | power_down 关闭/暂停，wake_up 恢复 |

## 2. 硬件分析

### 2.1 引脚（网表核实）

| 信号 | 引脚 | 网表证据 | 说明 |
|------|------|---------|------|
| RGB_DATA | **P0.20**（U36.32） | `RGB_DATA ; U35.4 U36.32` | WS2812 DIN，SPI3 MOSI |
| SPI3 SCK | **P0.17** | 外部 NC 但必须配置 | SPI3 时钟 |
| RGB_PWR_EN | **P0.13**（U36.33） | `RGB_PWR_EN ; Q4.1 R15.2 U36.33` | 高有效使能 RGB 供电（Q4→Q2 链路） |
| Chain | 17 颗 WS2812B-MINI | 网表 $1I7827~$1I7845 + RGB_1~4 级联 | U35→U3→U5→...→U33（已推演确认） |

**供电链路（已确认）**：
```
P0.13 (RGB_PWR_EN) → R15 → Q4(NPN, Q4.2=GND) → Q2(P-MOS) → RGB_VCC_OUT → 灯带 VDD
Q2: SYS_POWER(3.7-4.2V) 输入 → RGB_VCC_OUT 输出
P0.13 高 = 供电，低 = 断电
```

> 灯带 VDD 接 RGB_VCC_OUT（Q2 控制），**不是常供 3V3**。led_strip_en_event(false) 可真正断电。

### 2.2 Zephyr WS2812 SPI 支持

Zephyr 提供 **`worldsemi,ws2812-spi`** 驱动（`zephyr/drivers/led_strip/ws2812_spi.c`），搭配 **led_strip API**：
- `led_strip_update_rgb(dev, pixels, num_pixels)` — 更新整条灯带
- `led_strip_length(dev)` — 获取链长

**不需要自研驱动**，只需在 DTS 中声明 SPI 节点和 WS2812 设备。

## 3. 总体架构

```
button_event ──┐
theme_rgb_update_event ──┤
led_strip_en_event ──┐
                     ▼
             ┌─────────────────────────┐
             │ led_strip_module        │
             │ (src/app/led_strip.c)   │
             │                         │
             │ 1. 订阅三个事件         │
             │ 2. 维护主题色           │
             │ 3. 维护启停状态         │
             │ 4. 按键→LED 索引映射    │
             │ 5. Key fade 效果        │
             │ 6. 生命周期/电源        │
             └───────────┬─────────────┘
                         │ led_strip_update_rgb() （通过系统工作队列）
                         ▼
                 WS2812 SPI 驱动
```

### 3.1 关键设计：SPI 刷新在工作队列中执行

`k_timer` 回调运行在**系统时钟中断上下文**，不能直接调用阻塞式 SPI API。

**本方案通过 `k_work` 将实际 SPI 刷新调度到系统工作队列线程执行**：

```
k_timer 回调（中断上下文）
  → 只更新 _brightness / _active 数组（轻量、可中断）
  → k_work_submit(&_refresh_work)
  → 系统工作队列线程（线程上下文）
    → refresh_strip() → led_strip_update_rgb() → spi_write_dt()
```

这样 SPI 传输可以在线程上下文中正常等待完成，**不会出现 `spi_nrfx_spim: Timeout waiting for transfer complete` 刷屏**。

## 4. 模块设计

### 4.1 新增事件

#### `theme_rgb_update_event`

```c
struct theme_rgb_update_event {
    struct app_event_header header;
    struct led_rgb theme_color;   /* r/g/b */
};
```

#### `led_strip_en_event`

```c
struct led_strip_en_event {
    struct app_event_header header;
    bool enabled;                 /* true=开, false=关 */
};
```

### 4.2 模块状态

```c
static struct led_rgb _theme_color = { .r = 0, .g = 255, .b = 0 };  /* 默认绿色 */
static bool _strip_enabled = true;
static bool _powered_down;
static uint8_t _brightness[17];   /* 每颗 LED 的 fade 亮度（0~255） */
static bool _active[17];          /* 每颗 LED 是否处于点亮状态 */
```

### 4.3 按键 → LED 索引映射

`button_event.key_id` 是 CAF `KEY_ID(col,row)` 编码。需要建立 **物理键位 → LED 索引** 映射表。

```c
static const uint8_t _led_map[6][4] = {
    { 0xFF, 0xFF, 0xFF, 0xFF },  /* ROW0: 旋钮无灯 */
    { 0,    1,    2,    3    },  /* ROW1: NLock / * -  */
    { 4,    5,    6,    0xFF },  /* ROW2: 7 8 9         */
    { 7,    8,    9,    10   },  /* ROW3: 4 5 6 +       */
    { 11,   12,   13,   0xFF },  /* ROW4: 1 2 3         */
    { 14,   15,   0xFF, 16   },  /* ROW5: 0 . Enter     */
};
```

### 4.4 Key Fade 效果

```
button_event(pressed=true)
  → key_id 映射到 led_index
  → 该 LED 亮度 = 255（主题色）
  → 启动 fade 定时器（16ms 周期）
  → fade_tick_handler（中断上下文）更新 _brightness/_active
  → k_work_submit(&_refresh_work)
  → refresh_work_handler（工作队列线程）→ refresh_strip() → SPI 刷新
  → 亮度降到 0，停止 fade
```

**Fade 参数**：
- 周期：16ms
- 步进：4（255/4 → ~1024ms 渐隐）

### 4.5 主题色更新

```c
theme_rgb_update_event 到达
  → _theme_color = event->theme_color
  → k_work_submit(&_refresh_work)   // 刷新灯带
```

### 4.6 启停控制

```c
led_strip_en_event(enabled=true)
  → 打开供电（P0.13=1）
  → clear_strip()（清空数组 + 调度刷新）

led_strip_en_event(enabled=false)
  → 停止 fade 定时器
  → clear_strip()（清空数组 + 调度刷新）
  → 关闭供电（P0.13=0）
```

### 4.7 生命周期/电源

```c
power_down_event
  → 停止 fade 定时器
  → clear_strip()（清空数组 + 调度刷新）
  → 关闭供电（P0.13=0）

wake_up_event
  → 恢复供电（如果 _strip_enabled）
  → clear_strip()（清空数组 + 调度刷新）
```

## 5. DTS 配置

### 5.1 SPI 节点

在 `app.overlay` 中添加 SPI3 节点：

```dts
&spi3 {
    compatible = "nordic,nrf-spim";
    status = "okay";
    #address-cells = <1>;
    #size-cells = <0>;
    pinctrl-0 = <&spi3_default>;
    pinctrl-1 = <&spi3_sleep>;
    pinctrl-names = "default", "sleep";

    ws2812: ws2812@0 {
        compatible = "worldsemi,ws2812-spi";
        reg = <0>;
        spi-max-frequency = <6400000>;
        spi-one-frame = <0x70>;
        spi-zero-frame = <0x40>;
        chain-length = <17>;
        color-mapping = <LED_COLOR_ID_GREEN
                         LED_COLOR_ID_RED
                         LED_COLOR_ID_BLUE>;
    };
};
```

```dts
&pinctrl {
    spi3_default: spi3_default {
        group1 {
            psels = <NRF_PSEL(SPIM_MOSI, 0, 20)>,
                    <NRF_PSEL(SPIM_SCK,  0, 17)>;
        };
    };

    spi3_sleep: spi3_sleep {
        group1 {
            psels = <NRF_PSEL(SPIM_MOSI, 0, 20)>,
                    <NRF_PSEL(SPIM_SCK,  0, 17)>;
            low-power-enable;
        };
    };
};
```

### 5.2 供电 GPIO

```dts
rgb_pwr_en: rgb-pwr-en {
    compatible = "gpio-leds";
    rgb_pwr: rgb_pwr {
        gpios = <&gpio0 13 GPIO_ACTIVE_HIGH>;
    };
};
```

### 5.3 Kconfig（prj.conf 追加）

```conf
# WS2812 LED strip
CONFIG_LED=y
CONFIG_LED_STRIP=y
CONFIG_WS2812_STRIP_SPI=y
CONFIG_SPI=y
CONFIG_SPI_NRFX=y
```

## 8. 风险与注意事项

| 编号 | 风险 | 应对 |
|------|------|------|
| R1 | P0.17 未连接外部 | SPI 时钟仅用于 WS2812 位码生成，外部 NC 可接受 |
| R2 | SPI 频率/帧格式需实测 | 使用实测值 6.4MHz + 0x70/0x40 |
| R3 | LED fade 频率影响系统负载 | 使用 k_timer（仅更新数组）+ k_work（SPI 刷新） |
| R4 | 灯链物理序 ≠ 键位序 | 需要上板标定，建立映射表 |
| R5 | **在中断上下文调用阻塞式 SPI** | **必须通过 k_work 调度到工作队列线程执行**（本方案已修复） |
| R6 | 与 USB/BLE 共用资源 | LED 模块独立，不占用 HID/输入资源 |
