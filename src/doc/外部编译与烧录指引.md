## 3. 编译方法(任选其一)

### 3.1 方法 A:nRF Connect for VS Code(推荐)

1. 打开 VS Code,安装 **nRF Connect for VS Code** 扩展;
2. 打开项目目录 `F:\ble_key_workspace\02_code`;
3. 确认扩展检测到 NCS v3.2.3 与工具链(如未检测,在设置中指定
   `nrf-connect.topdir` 为 `F:\ncs\v3.2.3`);
4. 在 "Applications" 视图 → "Add build configuration":
   - **Board**: `BLE_keyboard`(自定义 board 会自动从工程 `boards/` 发现)
   - Build Configuration 保存;
5. 点击 Build,成功后点击 Flash。

### 3.2 方法 B:命令行 west

在 PowerShell 中设置环境并构建:

```powershell
# 1) 设置工具链
$tc = "F:\ncs\toolchains\fd21892d0f"
$env:PATH = "$tc\opt\bin;$tc\opt\bin\Scripts;$tc\mingw64\bin;$env:PATH"
$env:PYTHONPATH = "$tc\opt\bin\Lib;$tc\opt\bin\Lib\site-packages"

# 2) 设置 Zephyr / NCS
$env:ZEPHYR_BASE = "F:\ncs\v3.2.3\zephyr"
$env:ZEPHYR_TOOLCHAIN_VARIANT = "zephyr"
$env:ZEPHYR_SDK_INSTALL_DIR = "$tc\opt\zephyr-sdk"
$env:NRF_INSTALL_DIR = "F:\ncs\v3.2.3"

# 3) 指定自定义 board 路径(工程内的 boards/ 目录)
$env:BOARD_ROOT = "F:\ble_key_workspace\02_code"

# 4) 构建(在工程目录下)
cd F:\ble_key_workspace\02_code
west build -b BLE_keyboard -d build_blekey --sysbuild
```

> **注意**:若 `west build` 找不到 nrf 模块,可显式指定:
> ```powershell
> west build -b BLE_keyboard -d build_blekey --sysbuild `
>   -DZEPHYR_MODULES="F:\ncs\v3.2.3\nrf"
> ```

### 3.3 方法 C:直接用 CMake(不依赖 west)

```powershell
cd F:\ble_key_workspace\02_code
cmake -B build_blekey -GNinja -DBOARD=BLE_keyboard ^
  -DZEPHYR_BASE=F:/ncs/v3.2.3/zephyr ^
  -DZEPHYR_TOOLCHAIN_VARIANT=zephyr ^
  -DZEPHYR_SDK_INSTALL_DIR=F:/ncs/toolchains/fd21892d0f/opt/zephyr-sdk ^
  -DBOARD_ROOT=F:/ble_key_workspace/02_code ^
  -DZEPHYR_MODULES=F:/ncs/v3.2.3/nrf
cmake --build build_blekey
```

## 7. 已知注意事项

1. **构建时的 NCS 模块发现**:工程在 NCS workspace 外,首次构建若报 Kconfig 符号
   undefined(APP_EVENT_MANAGER/CAF_BUTTONS 等),按 §3.2 方法 B 第 4 步的
   `-DZEPHYR_MODULES` 指定 nrf 路径即可;
2. **应用 Kconfig 必须 source Zephyr**:工程根目录的 `Kconfig` 已包含
   `source "Kconfig.zephyr"`(与官方样例一致)。**切勿删除此行**,否则所有
   Zephyr/CAF 符号(LOG/GPIO/CAF_BUTTONS 等)会报 "undefined symbol" 并中止构建;
3. **sysbuild**:本期使用 `--sysbuild` 构建(与 NCS 标准一致),`Kconfig.sysbuild`
   已提供最简配置;若只想快速验证,也可不带 `--sysbuild`(Zephyr 经典单镜像);
4. **自定义 board**:board 在工程内 `boards/BLE_keyS/BLE_keyboard`,必须设置
   `BOARD_ROOT` 指向工程根目录,否则找不到 board;
5. **去抖说明**:CAF buttons 的去抖由内部防抖逻辑实现(SCAN_INTERVAL +
   DEBOUNCE_INTERVAL,当前 6ms),等效满足"按下/释放 10ms"需求;如需更精确
   10ms,可将 `CONFIG_CAF_BUTTONS_SCAN_INTERVAL` 和
   `CONFIG_CAF_BUTTONS_DEBOUNCE_INTERVAL` 调为 10;
6. **GPIO 极性**:行=下拉高有效、列=输出高有效,已在 buttons_def.h 中体现;
   CAF buttons 默认(非 POLARITY_INVERSED)即匹配此极性;
7. **键名打印编码**:中文键名经 Zephyr LOG 输出,需串口终端支持 UTF-8;
8. **qdec 节点**:EC11 A=P0.10、B=P1.06 已在 board dts 中配置,启用
   `CONFIG_INPUT_GPIO_QDEC` 即可;
9. **本期范围**:仅按键 + 旋钮(音量/静音)+ 串口日志;BLE/三模/显示屏后续阶段。

## 8. 常见问题

| 问题 | 解决 |
| --- | --- |
| `No board named 'BLE_keyboard'` | 设置 `BOARD_ROOT=F:\ble_key_workspace\02_code` |
| Kconfig 符号 undefined | 指定 `-DZEPHYR_MODULES=F:/ncs/v3.2.3/nrf` |
| dtc 崩溃(couldn't create signal pipe) | 沙盒/权限限制,换完整权限终端或 VS Code 终端执行 |
| 烧录失败 no device found | 检查 SWD 连接、nrfjprog 驱动 |
| 日志乱码(中文) | 终端选择 UTF-8 编码 |
