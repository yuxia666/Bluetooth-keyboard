## 1. 项目概述

### 1.1 产品定位

本产品是一款**单主控蓝牙数字小键盘**,面向桌面办公、数据录入、财务计算等场景,提供完整数字小键盘功能(数字键、运算符号、回车、退格、锁定等),并额外集成:

- **EC11 旋转编码器旋钮**(可作音量调节、页面滚动、快捷操作);
- **17 颗 WS2812B-MINI RGB 背光灯**(每键一灯,支持灯效);
- **SPI 接口显示屏**(通过 8P 排针外接 OLED/LCD);
- **锂电池供电**(XH2.54 电池座)+ **Type-C 充电**;
- **三模切换开关**(蓝牙 / 2.4G / 有线三模,依据原理图三模开关设计)。

### 1.2 产品形态

按键布局(依据原理图第一页键盘布局定义):

```
┌─────┐
│ Esc │(EC11 旋钮位,按下为按键)
├─────┬───┬───┬───┬───┐
│NLock │ / │ * │ - │   │
├─────┼───┼───┼───┤ + │
│ 7Home │ 8 │ 9PgUp │(2 行高)│
├─────┼───┼───┤   │   │
│ 4   │ 5 │ 6 │   │   │
├─────┼───┼───┼───┤   │
│ 1End │ 2 │ 3 │Enter│   │
├─────┴───┴───┴───┤   │
│  0Ins  (2列宽)  │ .Del │
└─────────────────┴───┘
```

即:标准 17 键数字区(0-9、`+ - * /`、`.`、`Enter`、`NumLock`、`Ins/Del` 复合)+ **Esc**(旋钮键),共 **18 个按键输入**(17 个机械轴 + 1 个 EC11 旋钮按键)。

### 1.3 核心指标(依据 E73-2G4M08S1C 模块手册与 nRF52840 规格书)

| 指标 | 参数 |
| --- | --- |
| 蓝牙版本 | BLE 5.0(兼容 BLE 4.2),2 Mbps / 1 Mbps / 500 kbps / 125 kbps |
| 主控 | nRF52840(QFN73),ARM Cortex-M4F @ 64 MHz,1 MB Flash / 256 KB RAM |
| 发射功率 | -20 ~ +8 dBm,软件多级可调 |
| 接收灵敏度 | -95 dBm @ 1 Mbps;-103 dBm @ 125 kbps(长距离模式) |
| 通信距离 | 理想空旷环境约 120 m(1 Mbps) |
| 供电范围 | 模块 1.7 ~ 5.5 V(3.3 V 供电保证最佳性能) |
| 天线 | 模块内置陶瓷天线(50 Ω) |
| 工作温度 | -40 ~ +85 ℃(工业级) |

### 2.2 电源树(依据网表电源网络)

```
USB-C VBUS (USB1.A4B9 / B4A9)
   │
   ├─→ U39.5 (USBLC6-2SC6,ESD 保护)
   ├─→ U2.1 (IP5306-I2C VIN,5V 充电输入)
   ├─→ U36.27 (模块 VBUS,USB 电源检测)
   └─→ R29(2Ω) ─ C33(10uF)(VBUS 滤波)

IP5306-I2C (U2) 锂电充放电管理:
   VIN(1) = VBUS
   LED1(2) = I2C_SCK(与主控 U36.35 通信)
   LED2(3) = I2C_SDA(与主控 U36.36 通信)
   KEY(5)  = 唤醒输入(经 R2/R26 接主控 IP5305T_WAKEUP;经 Q3 接 U41 单稳态输出)
   BAT(6)  = 电池正极 VBAT(经 R7 500mΩ 采样, C38 滤波)
   SW(7)   = 升压开关节点,接 U40(1uH 电感) → VBAT
   VOUT(8) = 5V 升压输出(C3/C23 22uF)
   EP/9    = GND

VBAT(电池,CN1 XH2.54 2P 连接器):
   └─→ U40.2(升压电感) / U41.2/3/8(单稳态 VCC) / C17/C32 滤波
       / R4(680k)-C22(1uF) 滤波 / R6(100k)-R8(100k) 分压 → BAT_ADC
       / R7(500mΩ) 采样 → U2.6

VOUT(5V) ──→ SW4(SK-22D02 电源总开关) ──→ SYS_POWER
SYS_POWER:
   ├─→ U37.1/3 (TPS7A3819 LDO 输入,EN 使能)
   ├─→ C25/C34(22uF) + C30(220uF) 储能
   └─→ Q2(P-MOS 高边开关,SYS_POWER→RGB_VCC_OUT)
        └ 控制:主控 RGB_PWR_EN(P0.13) → Q4 → Q2 栅极(R14/R15)

3V3(U37.5 LDO 输出):
   └─→ 主控 U36.19/23、屏幕接口 P3.6、上拉电阻组、LED 限流等

RGB_VCC_OUT(Q2.3 输出,受主控使能):
   └─→ 17 颗 WS2812B VDD + 每灯 100nF 去耦(C4~C7、C14~C21、C26~C28、C35~C37)
```

| 功能 | 引脚 | 说明 |
| --- | --- | --- |
| 供电 | VCC(19)、VDH(23) | 3V3;VDH 接 3V3 稳压输出 |
| 地 | GND(5/21/24) | 多点接地 |
| DC/DC | DCH(25) | 芯片 DC/DC 转换器输出,配合内部调节器 |
| 32.768kHz 晶振 | XL1(11)、XL2(13) | X1 晶振 + C12/C13(12pF 负载电容) |
| 复位 | RST(26) | SW2 复位键(10k 上拉 + 100nF 去抖) |
| USB 电源检测 | VBUS(27) | 接 VBUS 网络 |

### 2.4 键盘矩阵设计(6 行 × 4 列,18 键)

依据网表,矩阵结构如下(每键串联 1N4148W 二极管防串扰):

| 行\列 | COL0(U36.15) | COL1(U36.14) | COL2(U36.12) | COL3(U36.10) |
| --- | --- | --- | --- | --- |
| ROW0 (U36.28) | — | — | — | **EC11 旋钮按键**(SW3.E → D20) |
| ROW1 (U36.22) | U10 (D4) | U4 (D1) | U6 (D2) | U8 (D3) |
| ROW2 (U36.20) | U16 (D7) | U12 (D5) | U14 (D6) | — |
| ROW3 (U36.18) | U24 (D11) | U18 (D8) | U20 (D9) | U22 (D10) |
| ROW4 (U36.17) | U30 (D14) | U26 (D12) | U28 (D13) | — |
| ROW5 (U36.16) | U38 (D19) | U32 (D17) | — | U34 (D18) |

- 17 颗机械开关:`SMD_KEYBOARD-SW`(CPG151101S11-16 轴座),编号 U4~U38(奇数补位);
- 18 颗二极管:D1~D14、D17~D20(`1N4148W`);
- 矩阵接口:行 ROW0~ROW5、列 COL0~COL3,共 10 个主控 GPIO;
- EC11 旋钮(SW3,EC11E15244G1):A/B 相位经 C40/C31(100nF)滤波接主控 EC11A/EC11B;公共端按键 D 脚接 COL3,旋钮按键 E 脚经 D20 接 ROW0(独立按键);
- 扫描方式:支持逐行扫描/中断唤醒扫描,低功耗模式下降压轮询。

### 2.5 RGB 灯效系统(WS2812B-MINI × 17)

- 灯珠:U3、U5、U7 … U35,共 17 颗 `WS2812B-MINI-V3J`,单线级联;
- 数据链路(依据网表):
  - `RGB_DATA`(U36.32)→ U35.DIN → U35.DOUT → U3.DIN → … → U33(链尾);
  - 中间段按 4 段分组(RGB_1~RGB_4),便于故障定位与分区灯效;
- 供电:RGB_VCC_OUT(Q2 高边开关输出),**可整体关断省电**;
- 驱动:单 GPIO(P0.20),800 kHz 单线协议,Zephyr `ws2812` driver(SPI 位掩码驱动);
- 灯效规划:默认背光、呼吸、流光、雨滴、波浪、按需点亮、电量颜色提示、低电量闪烁等。

### 2.6 屏幕接口(P3,8P 排针 2.54mm)

| 引脚 | 信号 | 主控 | 说明 |
| --- | --- | --- | --- |
| 1 | SCREEN_BLK | P1.11 (U36.1) | 背光控制(PWM) |
| 2 | SCREEN_RES | P1.10 (U36.2) | 复位 |
| 3 | SCREEN_DC | P0.03 (U36.3) | 数据/命令选择 |
| 4 | SCREEN_SDA | AI4 (U36.4) | SPI MOSI |
| 5 | SCREEN_SCL | P1.13 (U36.6) | SPI SCK |
| 6 | 3V3 | — | 供电 |
| 7 | SCREEN_CS | AI0 (U36.7) | 片选 |
| 8 | GND | — | 地 |

- 目标屏:1.3"/1.54" SPI OLED(SSD1306/SSD1315)或 LCD(ST7789 等);
- 显示内容规划:电量百分比、连接状态、蓝牙名称、当前模式、层/按键映射提示、灯效名称等。

### 2.7 USB 接口(USB-C)

- USB1:Type-C 16PIN 连接器;
- CC1/CC2(A5/B5)经 R11/R12(5.1kΩ)下拉至 GND(设备/受电角色);
- D+/D-:A6/A7、B6/B7 → R24/R23(0Ω) → USBLC6-2SC6(U39,SOT-23-6)ESD+共模保护 → 主控 USB D+/D-(U36.29/31);
- VBUS:A4B9/B4A9 → VBUS 网络;
- 用途:充电、有线模式(HID over USB)、固件升级。

### 2.8 电源管理细节(IP5306-I2C)

依据 `IP5306-I2C手册.pdf`:

| 项目 | 参数 |
| --- | --- |
| 充电电流 | 最大 2.1 A(同步开关充电,效率 91%) |
| 放电电流 | 最大 2.4 A(同步升压,效率 92%) |
| 电池电压 | 4.20 V(定制型号支持 4.30/4.35/4.40 V) |
| 升压输出 | 5.0 V(VBAT=3.7V 时),开关频率 500 kHz |
| 待机功耗 | 空载自动休眠,< 100 µA |
| 充电截止 | 24 h 安全计时,再充电阈值 4.1 V |
| 保护 | 输入欠压、过充、过放、输出过流/过压/短路、过温,ESD 4 kV |
| I2C 接口 | 定制型号(IP5306-I2C),SCK/SDA 与主控通信,INT 状态指示 |
| 电感推荐 | 1.0 µH(SPM70701R0 级,本设计采用 VLS252012CX-150M,1uH) |
| 电池保护 IC | 推荐 IP3005A(ESOP8,过充 4.28V/过放 2.5V/过流 7A),U41 功能相关 |

**唤醒链路**(依据网表):
- 上电/唤醒:`SW4` 滑动开关产生 `MANUAL_WAKE` → `U41`(SN74LVC1G123DCTR 单稳态触发器)整形 → `Q3` 驱动 → IP5306 `KEY` 引脚,实现按键/开关开机;
- 主控唤醒:`IP5305T_WAKEUP`(P0.22)双向控制,主控可控制电源芯片,也可被唤醒;
- 电量采集:`BAT_ADC`(AI7)= VBAT 经 R6(100k)/R8(100k)分压,由 `BAT_ADC_EN`(NF1)使能 Q1 后采样(省电),C29 滤波。

### 2.9 三模切换(U1,SK-13D07-4 滑动开关)

- `MODE`(AI5,U36.8)经 R5(10k)接三模开关 U1;
- U1 多刀位组合 R16/R17(100k 上/下拉)、R18/R19/R20(1k)产生多电平/多态,区分**蓝牙 / 2.4G / 有线**三种工作模式(2.4G 预留,当前主控为单蓝牙模组,可扩展);
- 当前固件按"蓝牙 / 有线"两种实际可用模式 + 预留 2.4G 位实现。

### 2.10 状态指示与调试

- LED1(LTST-C230KFKT 红色,P1.02,经 R130 4.7k):连接状态(未连接快闪/已连接常亮/充电指示);
- LED2(红色,P1.07,经 R13 4.7k):充电/电量指示(可配合 IP5306 状态);
- H1 3P 调试排针:SWD + SCK + GND,配合 J-Link/nRF Connect 编程调试;
- 模块烧录方式(E73 手册):必须使用 J-Link(SWD),先用 nRFgo Studio 烧协议栈,再烧应用 hex;本设计采用 Zephyr + MCUboot 双分区(slot0/slot1 + storage,共 1MB Flash 划分)。

## 3. 软件架构规划(Zephyr RTOS)

### 3.1 开发环境

- Zephyr RTOS(板级: `boards/BLE_keyS/BLE_keyboard`,SoC: nrf52840_qiaa);
- 工具链:Zephyr SDK(arm-zephyr-eabi);
- 构建:west + CMake(现有工程 `CMakeLists.txt` + `prj.conf`);
- 分区(现有 `BLE_keyboard.dts`):MCUboot 48K + slot0 472K + slot1 472K + storage 32K,支持 DFU 升级。

### 3.2 软件模块划分

```
app/
├─ main.c                  # 入口、模块初始化、主循环
├─ key_matrix/             # 键盘矩阵扫描、去抖、防串扰(行列扫描)
├─ ec11/                   # 旋钮解码(正交编码器,带 100nF 滤波)
├─ hid/                    # BLE HID 键盘上报(数字小键盘 HID 映射)
│                            - HID Report Map(NumLock/+/Enter/Del 等)
│                            - NKRO/6KRO 选择
├─ ble/                    # BLE 广播/连接/重连/配对(自定义名称"BLE_key")
├─ usb/                    # USB HID(有线模式,USB-C 接入时自动切换)
├─ power/                  # IP5306 I2C 控制、电量读取、充电状态、
│                            BAT_ADC 采样、低电量策略、待机/唤醒
├─ rgb/                    # WS2812B 驱动与灯效引擎(17 灯)
├─ display/                # SPI 屏幕驱动(SSD1306/ST7789)+ 界面
├─ mode/                   # 三模切换检测(U1 滑动开关)
└─ config/                 # 配置存储(Flash settings:键值、灯效、亮度)
```

### 3.3 关键软件设计点

1. **BLE HID 键盘**:使用 Zephyr `CONFIG_BT_HIDS`(HID Device Service),上报数字键与修饰键;支持多连接(最多 3 台设备,存储 8 个绑定);
2. **矩阵扫描**:6×4 小矩阵,行输出列输入(或反之),4~8 ms 周期,防抖 10~20 ms;休眠时使用 GPIO 唤醒扫描;
3. **旋钮解码**:EC11 A/B 相位,状态机解码,支持加速(快速旋转大步长),可映射音量/滚动/光标;
4. **灯效引擎**:WS2812B 单线协议,SPI 位掩码方式驱动(如 nrfx_spim + 位图);提供基础灯效 API,中断驱动更新,不阻塞扫描;
5. **电源策略**:
   - 空闲无连接:进入低功耗(System ON + RTC,~µA 级);
   - 深度待机:系统 OFF,由按键/旋钮/电源开关唤醒(经 U41 单稳态链路);
   - RGB 空闲自动关断(RGB_PWR_EN 拉低);
   - 电量分级告警(≥25% 正常,10~25% 提示,<10% 低电闪烁并限制灯效);
6. **屏幕**:SPI 刷屏,电量/状态界面,支持 PWM 背光调节(SCREEN_BLK);
7. **有线模式**:USB-C 插入检测(VBUS/CC),自动切换 USB HID,支持 USB 充电同时工作(边充边用);
8. **DFU 升级**:MCUboot + SMP(或 USB CDC/串口),支持后续 OTA。

## 5. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 蓝牙频段干扰(2.4G/WiFi/USB3.0) | 连接不稳、距离下降 | 良好天线布局、屏蔽、信道选择、重连机制 |
| 电池供电下 WS2812B 峰值电流 | RGB 全亮时电流大,压降/闪屏 | 独立 RGB_VCC_OUT 开关、灯效亮度限制、软件限流 |
| IP5306 休眠策略与主控不同步 | 误休眠/无法唤醒 | 使用 WAKEUP/KEY 双向链路 + U41 单稳态保脉冲;联调确认时序 |
| 三模切换硬件为滑动开关 | 切换需手动,无法软件切换 | 固件读取 MODE 电平自动切换;2.4G 位预留 |
| 矩阵+旋钮共用 COL3 | 扫描冲突 | 二极管隔离 + 扫描时序错开 |
| 大电流充电发热 | 充电效率/安全 | 限流 1A 档、散热、过温保护 |
| MCUboot 双分区容量 | 应用空间受限(472K) | 裁剪、符号表控制、必要时压缩灯效表 |
| 天线被壳体/走线遮挡 | 距离骤降 | 遵循 E73 手册布局要求(天线净空、顶层铺地) |

## 6. 测试与验收规划

1. **硬件测试**:
   - 电源测试:VBUS/VBAT/SYS_POWER/3V3/RGB_VCC_OUT 电压与纹波;
   - 充电测试:充电电流、截止电压(4.2V)、涓流/恒流/恒压段;
   - 放电/续航:满电空载待机电流、RGB 关闭/开启续航;
   - 按键矩阵全键测试、旋钮旋转/按下测试(含 100nF 滤波下边沿质量);
   - USB:充电 + 有线 HID + D+/D- 眼图(如有条件)。
2. **RF 测试**:
   - 发射功率、接收灵敏度、连接距离(空旷/室内);
   - 多设备绑定、重连、休眠唤醒。
3. **软件测试**:
   - 键值上报正确性(所有键 + 组合键);
   - 灯效稳定性(长时间运行无卡死);
   - 低功耗电流实测(System ON / OFF);
   - DFU 升级回退。
4. **环境测试**:
   - 温度循环(-20~60℃ 功能正常)、ESD 4kV 打点、跌落。
